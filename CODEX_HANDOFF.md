## What this is

Murder Board sorts a homicide case file and judges it. Ten AI
agents, each a real homicide-squad job, work one file in a fixed
order and post to one board: person cards, one timeline, an
evidence ledger, contradiction findings with verbatim quotes,
alibi ratings, a gap list, scored leads, and a detective's brief.
It judges the file, never a person. The detective does the
detecting.

- Live demo: https://murder-board.pages.dev (replay mode works
  with no key; both cases have saved runs)
- Repo: github.com/mrfentmen/murder-board (public, main)
- Built at Gemini 4 NYC, 2026-11-21. Demo deadline was 5 PM; the
  build was demo-ready by ~11:35 AM.

## Architecture (app/)

Static page app, no framework, no build step.

- `app/index.html`, `app/style.css`, `app/app.js` — everything.
  `app.js` is UMD-shaped: the same runner works in the browser
  and in Node (the test harness requires it).
- `app/case-data.js` — GENERATED by `tools/build_data.py` from
  `case/` and `case2/`. Never edit by hand.
- `app/agents-data.js` — GENERATED from `agents/*.md` (11 step
  prompts; 10 chairs, the First Officer's chair covers steps 01
  custody and 05 intake).
- `app/cache-data.js` — GENERATED by `tools/merge_cache.py` from
  `cache/*.json`. The replay caches. Never edit by hand.
- `app/config.js` — the API key, gitignored, NEVER commit it.
  Copy `app/config.example.js`. A leaked key on this project
  gets every key on it killed automatically.
- Transport: browser fetch to `generativelanguage.googleapis.com`
  with the `x-goog-api-key` header, or `window.__MB_TRANSPORT`
  override (the Node harness injects one that shells to a local
  connector helper).

Model map (config): reasoning model `gemini-4-argon` runs
Cross-Examiner and Lead Detective; fast model `gemini-3.8-flash`
runs everything else.

### The runner's three laws (code, not prompt wishes)

1. **No quote, no finding.** Every finding carries a document id
   and an exact quote. `quoteOk` in app.js checks the quote is a
   whitespace/case-normalized verbatim substring of the cited
   document. Failures are dropped, counted, and the count is
   shown on the Judgments screen.
2. **The runner owns the arithmetic.** Lead scores are recomputed
   from declared components (40 high contradiction / 25 in the
   death window / 20 closes a gap / 15 still reachable). The
   runner's number wins over the model's.
3. **A failed step never kills the run.** One retry (schema or
   parse), then the chair shows red and the run continues.

Run order: First Officer (custody) → Records → Coroner → CSI →
Intake → Analyst → Digital → Cross-Examiner → Interviewer →
Prosecutor → Lead Detective. Conflict rule: record beats
statement, body beats both, and the brief shows the fight.

## How to run things

```bash
# regenerate data after editing case/ or agents/
python3 tools/build_data.py

# serve the app
cd app && python3 -m http.server 8000   # then open localhost:8000

# full live run for one case (needs a working Gemini key path;
# writes cache/<case-id>.json)
MB_CASE_ID=screens-2025 node tools/run_live.js

# re-run only the steps missing from a case's cache
MB_CASE_ID=delgado-2019 node tools/repair_run.js

# after any cache change
python3 tools/merge_cache.py
```

Note: `tools/run_live.js` reaches the API through Del's local
connector helper on Pax's machine. On any other machine, give
the harness a transport of your own (set `__MB_TRANSPORT`) or
just run live in the browser with `config.js`.

**Key warning:** the Gemini key used at the event belonged to a
temporary hackathon account that is deleted the day after the
event. After 2026-11-22, live runs need a fresh key from Del.
Replay mode needs nothing.

## Adding a case

1. New folder `caseN/` with one `.txt` per document and a
   `registry.json` (see `case2/registry.json` for the shape).
2. Add the folder to `load_case` calls in `tools/build_data.py`.
3. Write its bible with planted catches and expected output,
   like `CASE2_BIBLE.md`. No bible, no case: the catches are
   the acceptance test.
4. Run it live, score it against the bible, save the cache.

## House rules (do not break)

- No quote, no finding. Never weaken the quote check.
- Judges the file, never a person. Every contradiction carries
  its innocent reading.
- Fictional cases only in this repo. No real people's names, no
  real cases, no scraped real posts presented as evidence.
- Never commit `config.js`, keys, or `cache/` raw outputs beyond
  what merge_cache publishes.
- The brief ends with the standing line: "This board judges the
  file. The detective does the detecting."
- Smallest sensible change; read the file before you rewrite it;
  label your status VERIFIED only for what you actually ran.
